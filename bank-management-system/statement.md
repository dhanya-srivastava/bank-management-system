## 🔐 Transaction Security

The system validates every transaction before processing it.

It ensures:

- Valid account numbers are used.
- Transaction amounts are positive.
- Withdrawals follow account-specific balance rules.
- Transfers are processed atomically.
- Failed transactions can be rolled back using JDBC transactions.
- Transaction activities are recorded in the log file.

---

## 📝 Logging

All important banking operations are recorded in:
